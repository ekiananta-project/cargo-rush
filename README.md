# Cargo Rush 🚜📦

Cargo Rush adalah game puzzle kargo 6×6 berbasis HTML/CSS/JavaScript yang dikemas untuk Android menggunakan Capacitor.

**Baseline gameplay:** V1.4 (disetujui untuk drag, collision, cancel, efek clear, dan suara combo).

## Menjalankan di browser
Buka `www/index.html` setelah aset game diunggah.

## Build APK debug
Workflow `.github/workflows/android-apk.yml` akan menghasilkan artifact APK debug melalui GitHub Actions setelah source web (`www/`) lengkap. APK debug untuk pengujian, bukan APK rilis Play Store.

Kerangka repository sedang disiapkan. Source web lengkap harus ditambahkan sebelum build pertama.
